para subir a git
Para actualizar tu repositorio remoto en GitHub con todos los cambios recientes que hemos hecho en el proyecto, abre la terminal en VS Code (asegúrate de estar en la raíz de tu proyecto C:\sumix) y sigue estos tres sencillos comandos:
1. Preparar y rastrear todos los cambios
Bash

git add .

2. Guardar el estado local con un mensaje claro
Bash

git commit -m "reportes de cierres arreglados y cierre actualizado para que descuente salario y 3%"

3. Subir las actualizaciones a GitHub
Bash

git push

En caso de que se presente alguna eventualidad:

    Si git push pide especificar la rama:
    Ejecuta:
    Bash

    git push origin main

    (O master, según el nombre de tu rama principal).

    Para confirmar que el estado local quedó limpio:
    Puedes verificar el estado ejecutando:
    Bash

    git status

    nombre = db.Column(db.String(100), nullable=False)

    # pero le decimos que en la base de datos física busque la columna 'username'
    usuario = db.Column('username', db.String(50), unique=True, nullable=False)
    
    password = db.Column(db.String(200), nullable=False)
    es_admin = db.Column(db.Boolean, default=False)
    
    # Y tu nueva relación de almacenes que acabamos de agregar:
    almacen_id = db.Column(db.Integer, db.ForeignKey('almacenes.id'), nullable=True)
    almacen = db.relationship('Almacen', backref='usuarios')
